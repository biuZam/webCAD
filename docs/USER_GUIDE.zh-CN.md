LeatherDraft 是一款用于绘制皮具版型的二维制图工具。以毫米为单位绘图，按 1:1 真实尺寸打印或切割。它在浏览器中运行（也有桌面版），无需注册账号，文件只保存在你自己的设备上。

## 1. 界面

| 区域 | 内容 |
| --- | --- |
| **工具栏**（顶部） | 项目名称、新建、打开…、保存、导入…、导出…、撤销 / 重做、快捷键…、语言 |
| **工具面板**（左侧） | 按组排列的全部工具。右下角带小三角的格子里还有同组工具：**右键**单击（或长按，或获得焦点时按 →）即可选择。每个格子会记住上次使用的工具。 |
| **绘图区**（中央） | 以毫米为单位、带网格的画布。工具提示和用于输入数值的**输入栏**显示在这里。 |
| **侧边栏**（右侧） | **图层**和**属性**面板。点击顶部的箭头可收起。 |
| **状态栏**（底部） | 光标 X/Y 坐标、缩放比例、网格间距、对象数与已选数量、显示单位，以及**捕捉**菜单。 |

每个工具都会显示一行提示，告诉你下一步该单击什么或输入什么。不确定时请看提示。

## 2. 基础操作

### 选择

使用**选择**工具（V）：

- 单击对象即可选中；**Shift+单击**加选或减选。
- **从左向右**拖框，选中完全在框内的对象；**从右向左**拖框，选中所有被框接触到的对象。
- **拖动**已选对象可移动；拖动时按住 **Alt** 则移动出一个副本。
- **Delete** 删除所选对象。**⌘/Ctrl+A** 全选。**Esc** 取消选择。

**编辑节点。** 选中一个图形后，会显示它的节点和贝塞尔控制柄：

- 拖动节点或控制柄即可移动。
- **双击节点**，在平滑和尖角之间切换。
- **双击轮廓**，添加节点。
- 单击节点后按 **Delete**，删除该节点。

### 输入精确数值

所有绘图和编辑工具都可以输入数值。**直接开始输入数字**，数字会进入输入栏。

- **Tab** 切换到下一项（例如 长度 → 角度，或 X → Y）。
- **Enter** 确认，**Esc** 清除。
- 长度使用状态栏中选定的显示单位（mm、cm 或 in）。角度以度为单位，自 +X 方向起逆时针计算。

绘图时按住 **Shift**，可将角度锁定为 15° 的倍数。

### 捕捉

光标会自动捕捉已有的几何图形。在状态栏中打开**捕捉**菜单，可分别开关各类捕捉：

端点 · 中点 · 圆心 · 象限点 · 交点 · 垂足 · 切点 · 最近点 · 网格 · 极轴追踪（45°）· 对象追踪

光标处的标记会显示当前生效的捕捉类型。

### 视图操作

- **鼠标滚轮**或触控板双指缩放：以光标为中心缩放。
- **按住空格拖动**或**按住中键拖动**：平移。
- 缩放比例显示在状态栏中；100% 时 1 mm 显示为 96/25.4 个 CSS 像素（名义上的实际大小）。

### 撤销

**⌘/Ctrl+Z** 撤销，**⇧⌘Z / Ctrl+Shift+Z**（或 Ctrl+Y）重做。每个操作恰好是一个撤销步骤，包括它所带动更新的关联缝线和缝孔。同一会话内撤销次数不限。

## 3. 绘图工具

新图形会画在**当前图层**上（见[图层](#8-图层与属性)）。大多数工具用 **Enter、双击或右键**结束图形，**Backspace** 撤回最后一个点。

| 工具 | 快捷键 | 用法 |
| --- | --- | --- |
| **直线** | L | 单击各点，或输入长度和角度。与 CAD 一样，每一段都是独立的对象。单击第一个点可闭合。 |
| **多段线** | （直线组） | 与直线相同，但所有线段组成一条路径。在直线工具的*方式*中切换。 |
| **矩形** | R | 单击两个角点，或输入宽度和高度。第一次单击时按住 **Alt** 可从中心绘制。设置*圆角半径*可得到圆角矩形。 |
| **正方形** | （矩形组） | 只需一个*边长*的矩形。 |
| **圆** | C | 单击圆心，再单击圆上一点，或输入半径。 |
| **三点圆** | （圆组） | 依次单击圆经过的三个点。 |
| **椭圆** | （圆组） | 单击中心，再单击第一条轴的端点，然后确定另一半径。 |
| **钢笔（曲线）** | P | 单击创建尖角点，**拖动**创建平滑曲线点。输入长度和角度可画直边。单击第一个点可闭合。 |
| **三点圆弧** | A | 依次单击起点、终点和圆弧经过的一点。 |
| **中心线** | X | 单击一个图形，在其中心添加竖直或水平中心线；也可用两点绘制。中心线可作为镜像轴。 |
| **垂线** | T | 单击一条直边，再放置与之垂直的线（或输入沿边距离和长度）。 |
| **平行线** | G | 单击一条直边，再在所需一侧和距离处单击，或输入距离。 |
| **标注** | N | *文字*方式：单击文字起点，输入文字（例如“前片 · 裁 2 片”），按 Enter。*纹理方向箭头*方式：单击两端。标注放在“备注”图层。 |

## 4. 修改图形

### 变换

**移动、旋转、缩放、镜像**和**阵列**作用于所选对象。如果没有选中任何对象，工具会先让你选择，选好后按 **Enter** 或右键。勾选**保留原对象（复制）**可对副本进行变换。

| 工具 | 快捷键 | 步骤 |
| --- | --- | --- |
| **移动** | M | 基点 → 目标点，或输入 ΔX 和 ΔY。 |
| **旋转** | O | 旋转中心 → 单击确定角度，或直接输入。Shift 取整到 15°。 |
| **缩放** | S | 基点（保持不动）→ 输入比例；或单击参考点，再单击它的目标位置。 |
| **镜像** | I | 单击一条中心线以其为轴镜像；或单击轴线上的两点（或一点再输入轴线角度）。 |
| **阵列** | Q | *线性*：基点 → 下一个副本的位置；*数量*包含原对象。*环形*：中心 → Enter；360° 时副本均匀分布一周，小于 360° 时首尾副本跨越该角度。 |
| **水平翻转 / 垂直翻转** | Shift+H / Shift+V | 原地立即翻转所选对象。 |

### 编辑

| 工具 | 快捷键 | 步骤 |
| --- | --- | --- |
| **偏移** | E | 单击路径、圆或中心线，再单击偏移的一侧。距离跟随光标，也可直接输入。*拐角*：尖角（斜接）、圆角或斜切。再次单击可继续偏移；Esc 重新选择对象。 |
| **圆角** | F | 将鼠标移到两条直边之间的拐角上，单击倒圆角。**Shift+单击**为该图形的所有拐角倒圆角。输入半径可修改；半径过大时，提示会给出可容纳的最大半径。 |
| **倒角** | B | 与圆角类似，但将拐角切成直边。输入两个距离，或一个距离和一个角度。 |
| **修剪 / 延伸 / 打断** | W | *修剪*：单击要删除的线段，修剪到最近的交点。*延伸*：单击线的端点附近，延伸到遇到的下一条线。*打断*：单击线，在该点打断。Shift+单击可在修剪和延伸之间切换。 |
| **连接路径** | Shift+J | 将首尾相接的所选开放路径连接为一条；一条首尾相接的路径则被闭合。 |
| **分解** | Shift+X | 将所选矩形、多段线或轮廓拆成单独的线段。 |
| **并集** | Shift+U | 将两个或更多所选闭合图形合并为一个轮廓。 |
| **差集** | Shift+D | 用其余所选闭合图形去减最大的那个。 |

## 5. 皮具专用工具

这些工具是 LeatherDraft 区别于通用 CAD 软件的地方。它们生成的对象**保持关联**：修改轮廓，缝线随之更新；缝孔又随缝线更新。这一切都在同一个撤销步骤内完成。

### 缝线（K）

1. 单击一个轮廓。
2. 单击内侧或外侧以确定方向。边距取自项目设置（见下文），也可直接输入其他数值。

缝线画在“缝线”图层上，此后会一直跟随其轮廓。要解除关联，选中缝线后在属性面板中点击**解除关联**。

### 缝孔（H）

1. 在输入栏中设置选项：
   - **菱斩**针距：2.7、3.38、3.85、4.0 或 5.0 mm，或**自定义**。
   - **孔径**和**孔形**：*圆孔*或*斜孔（菱斩）*。
   - **每个拐角都打孔**：每条边的孔距会被均匀调整，使每个拐角上正好有一个孔，就像实际用菱斩走线一样。
2. 将鼠标移到缝线（或任意线）上，预览缝孔及孔数。
3. 单击添加。

之后可在属性面板中修改针距、孔径或孔形；**每边孔数**列出每条边上的孔数。

### 项目默认值

不选中任何对象时，属性面板中的**项目**部分用于设置新缝线和缝孔的默认值：**缝线边距**（3.5 mm）、**针距**（3.85 mm）和**孔径**（1.2 mm），括号内为初始值。

### 缝份（Y）

1. 单击一个闭合轮廓。
2. 输入一个数值应用到所有边；或单击某些边（Shift+单击多选），只为这些边输入数值。
3. 未输入任何数值时按 **Enter**，添加缝份轮廓。

### 冲孔 / 腰圆孔（U）

用于铆钉、四合扣、螺丝扣和皮带扣针。选择*圆孔*或*腰圆孔*，选择常用的**圆冲**直径或**自定义**，然后单击放置（可捕捉圆心和端点），或输入 X/Y 后按 Enter。腰圆孔的*长度*为两端总长，*宽度*即圆冲直径。

### 对位刀口（J）

用于组装时对位的标记。选择*单刀口*或*双刀口*，*直线刀口*或 *V 形刀口*，设置深度（以及间距 / 宽度），然后单击边缘。刀口朝向部件内侧；开放线条上则朝向光标一侧。

### 线型

在属性面板中设置路径的**线型**：*实线（裁切）*、*虚线（折线/压痕）*、*点线（参考）*或*点划线（中心线）*。**线宽（导出）**设置导出文件中使用的线宽。

## 6. 约束

**约束**工具（Z）让图形之间的关系变得精确。每种约束中，**先**单击的对象保持不动，**后**单击的对象会移动。

| 类型 | 单击 |
| --- | --- |
| **平行** / **垂直** | 两条直边。 |
| **相切** | 一条直边或一个圆，再单击要与之相切的圆（或直边）。 |
| **重合** | 两个点。 |
| **距离** | 两个点，然后输入距离并按 Enter（直接按 Enter 保持当前值）。 |
| **半径** | 一个圆，然后输入半径并按 Enter。 |

如果新约束与已有约束冲突，图形不会被修改，提示中会说明原因。

选中对象后，属性面板的**约束**部分会列出其约束。标为*未满足*表示求解后几何又被移动过，点击**求解**即可恢复。标为*已失效*表示其引用的对象已改变或被删除，可用 × 按钮删除该约束。

## 7. 测量

**测量**工具（D）有四种方式：

- **距离**：单击两点。
- **角度**：依次单击一点、角点和另一点。
- **长度**：将鼠标移到图形上查看其长度。
- **孔数**：单击缝孔的一条边，再单击要与之缝合的边。提示会告诉你孔数是否一致，或相差几个孔，便于在裁切前调整针距或边长。

## 8. 图层与属性

### 图层

每个图纸都有四个图层：

| 图层 | 用途 |
| --- | --- |
| **裁切** | 需要裁切的轮廓。 |
| **缝线** | 缝线和缝孔。 |
| **参考** | 辅助线和导入的图形。 |
| **备注** | 标注和纹理方向箭头。 |

每个图层都可以**显示 / 隐藏**（复选框）、修改**颜色**（色块）、**锁定 / 解锁**（锁形按钮），单击图层名称即可**在该图层上绘制**。已锁定或已隐藏的图层不能绘制。

### 属性

选中对象即可查看和编辑其数值：位置、宽和高、长度、半径或直径、旋转、图层、线型、文字、针距等。输入数值后按 Enter。选中多个对象时，数值不同的项显示为“—”，输入新值会同时应用到所有对象。

### 单位

在状态栏中选择 **mm**、**cm** 或 **in**。这只影响显示和输入，图纸始终以毫米存储。

## 9. 文件

- **保存**（⌘/Ctrl+S）写入 `.json` 项目文件。**⌘/Ctrl+Shift+S** 另存为新文件。
- **打开…**（⌘/Ctrl+O）打开 `.json` 项目。
- **新建**创建空白项目（如有未保存的更改，会先询问）。
- 项目名称显示在工具栏中；浏览器标签页标题前的圆点表示有未保存的更改。
- **导入…**可将 **SVG 或 DXF** 文件按实际尺寸导入到“参考”图层，并自动选中，便于描摹已有版型。
- **自动保存**：每次修改后半秒，作品会保存在浏览器中，下次打开 LeatherDraft 时自动恢复。自动保存只是安全保障，不能代替保存文件：清除浏览器数据会将其删除。

**桌面版**：保存、打开和导出使用系统的文件对话框，保存时会持续写入同一个文件。

**离线使用**：网页版加载一次后即可离线使用（提示“已可离线使用”）。有新版本时，会出现**重新加载**提示。

## 10. 导出与打印

点击**导出…**打开导出对话框。

| 格式 | 用途 | 选项 |
| --- | --- | --- |
| **PDF** | 1:1 打印 | 纸张（A4、Letter、A3，或用于大幅面打印机的**单页，按版型尺寸**）、方向（*页数最少*、纵向、横向）、页间重叠 |
| **SVG** | 激光切割机、刻字机、Inkscape、Illustrator | 曲线转为短直线（适用于无法读取曲线的激光软件） |
| **DXF** | 激光与 CNC 软件，单位为毫米 | 只包含图形，不含标注文字 |
| **PNG** | 分享图片 | 分辨率：96、150 或 300 dpi。不能用于制作版型。 |

通用选项：**仅裁切图层（激光）**、**包含标注**、**线宽**，以及**水印**（文字和不透明度；PDF 中会在每一页重复显示）。

如果图纸中有由 AI（通过 MCP 服务器）创建、尚未复核的对象，导出对话框会提醒你。可在状态栏中选中它们，检查无误后在属性面板中点击**标记为已复核**。

### 按实际尺寸打印

分页 PDF 的第一页是**拼接页**：包含各页的拼接示意图和一个 **50 mm 校准方块**。每一页都带有裁切标记和页码标签（A1、A2、B1…）。

1. 按 **100% /“实际大小”**打印。切勿选择“适合页面”或“缩小超大页面”。
2. **测量 50 mm 方块。** 如果不是正好 50 mm，请检查打印机缩放设置后重新打印。
3. 沿虚线裁剪或叠放各页，对齐角标和页边的页码标签，然后用胶带拼接。

| 按住 Shift | 角度锁定为 15° 的倍数 |
| 按住 Alt | 矩形从中心绘制；拖动时复制 |
| 数字键 | 开始输入数值 |

## 12. 实例：绘制一个卡包部件

1. **矩形**（R）：单击一次，输入 `95`，Tab，`65`，Enter。“裁切”图层上就有了一个 95 × 65 mm 的部件。
2. **圆角**（F）：输入 `5`，然后 **Shift+单击**任一拐角，四个角全部倒圆角。
3. **缝线**（K）：单击轮廓，再单击内侧。使用默认边距时，缝线在轮廓内侧 3.5 mm 处。
4. **缝孔**（H）：选择针距 **3.85**，勾选**每个拐角都打孔**，将鼠标移到缝线上并单击。
5. **标注**（N）：在部件内单击，输入 `卡包 · 裁 2 片`，按 Enter。
6. 试着修改轮廓：选中矩形，在属性面板中将**宽**改为 `100`。缝线和缝孔会随之更新。
7. **保存**（⌘/Ctrl+S），然后 **导出…** → PDF → A4 → 按 100% 打印，并测量 50 mm 方块。

## 13. 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 画不出图形 / 提示“当前图层已锁定或隐藏” | 解锁或显示该图层，或在“图层”面板中选择其他图层。 |
| 打印出来略大或略小 | PDF 被缩放了。请按 100% /“实际大小”打印，并重新测量 50 mm 方块。 |
| 圆角提示“对此拐角过大” | 使用提示中给出的最大半径，或加长边。 |
| 要缝合的两条边孔数不一致 | 使用 测量 → 孔数 检查，然后调整针距或其中一条边的长度。 |
| 约束提示“冲突” | 新约束与已有约束矛盾。在 属性 → 约束 中删除其中一个。 |
| 激光软件中的曲线显示异常 | 导出 SVG 时勾选**曲线转为短直线**，或改用 DXF。 |
| 快捷键没有反应 | 可能有文本框处于焦点状态：先单击画布。另请在**快捷键…**中确认该键没有被重新分配。 |
