## 1. 화면 구성

| 영역 | 내용 |
| --- | --- |
| **도구 모음**(상단) | 프로젝트 이름, 새로 만들기, 열기…, 저장, 가져오기…, 내보내기…, 실행 취소 / 다시 실행, 단축키…, 언어 |
| **도구 팔레트**(왼쪽) | 모든 도구가 그룹별로 정리되어 있습니다. 모서리에 작은 삼각형이 있는 칸에는 도구가 더 들어 있습니다. **마우스 오른쪽 클릭**(길게 누르기, 또는 포커스 상태에서 → 키)으로 다른 도구를 고를 수 있습니다. 칸은 마지막으로 쓴 도구를 기억합니다. |
| **작업 영역**(가운데) | 밀리미터 단위의 격자가 있는 캔버스입니다. 도구 안내 문구와 값을 입력하는 **입력 막대**가 여기에 나타납니다. |
| **사이드 패널**(오른쪽) | **레이어**와 **속성**. 상단 화살표로 접을 수 있습니다. |
| **상태 막대**(하단) | 커서 X/Y 좌표, 확대/축소 비율, 격자 간격, 객체 수와 선택된 객체 수, 표시 단위, **스냅** 메뉴. |

각 도구는 다음에 클릭하거나 입력할 내용을 한 줄로 안내합니다. 잘 모르겠다면 이 안내를 읽어 보세요.

## 2. 기본 조작

### 선택

**선택**(V) 도구를 사용합니다.

- 객체를 클릭해 선택합니다. **Shift+클릭**으로 추가하거나 제외합니다.
- **왼쪽에서 오른쪽**으로 드래그하면 상자 안에 완전히 포함된 객체를 선택합니다. **오른쪽에서 왼쪽**으로 드래그하면 상자에 닿은 모든 객체를 선택합니다.
- 선택한 객체를 **드래그**하면 이동합니다. 드래그하는 동안 **Alt**를 누르면 복사본을 이동합니다.
- **Delete**로 선택을 삭제합니다. **⌘/Ctrl+A**는 전체 선택, **Esc**는 선택 해제입니다.

**점 편집.** 도형을 하나 선택하면 점과 베지어 핸들이 나타납니다.

- 점이나 핸들을 드래그해 옮깁니다.
- **점을 더블클릭**하면 부드러운 점과 모서리 점을 전환합니다.
- **외곽선을 더블클릭**하면 점이 추가됩니다.
- 점을 클릭한 뒤 **Delete**를 누르면 해당 점이 삭제됩니다.

### 정확한 값 입력

모든 그리기 및 편집 도구는 숫자 입력을 받습니다. **숫자를 입력하기만 하면** 입력 막대로 들어갑니다.

- **Tab**으로 다음 입력 칸으로 이동합니다(예: 길이 → 각도, X → Y).
- **Enter**로 적용하고, **Esc**로 지웁니다.
- 길이는 상태 막대에서 고른 표시 단위(mm, cm, in)를 따릅니다. 각도는 도(°) 단위이며, +X 방향에서 반시계 방향으로 잽니다.

그리는 동안 **Shift**를 누르고 있으면 각도가 15° 단위로 고정됩니다.

### 스냅

커서는 기존 도형에 스냅됩니다. 상태 막대의 **스냅**을 열면 종류별로 켜거나 끌 수 있습니다.

끝점 · 중간점 · 중심 · 사분점 · 교차점 · 수직 · 접점 · 가장 가까운 점 · 격자 · 극좌표 추적(45°) · 객체 추적

커서 위의 표시로 현재 활성화된 스냅을 확인할 수 있습니다.

### 화면 이동

- **마우스 휠** 또는 트랙패드 핀치: 커서 위치를 기준으로 확대/축소합니다.
- **Space + 드래그** 또는 **가운데 버튼 드래그**: 화면을 이동합니다.
- 확대/축소 비율은 상태 막대에 표시됩니다. 100 %에서는 1 mm가 96/25.4 CSS 픽셀로 그려집니다(명목상의 실제 크기).

### 실행 취소

**⌘/Ctrl+Z**로 실행 취소하고, **⇧⌘Z / Ctrl+Shift+Z**(또는 Ctrl+Y)로 다시 실행합니다. 모든 작업은 한 번의 실행 취소 단계이며, 함께 업데이트되는 연결된 스티치 선과 구멍도 포함됩니다. 세션 중에는 횟수 제한이 없습니다.

## 3. 그리기 도구

새 도형은 **현재 레이어**에 만들어집니다([레이어](#8-레이어와-속성) 참고). 대부분의 도구는 **Enter, 더블클릭 또는 오른쪽 클릭**으로 도형을 완성하며, **Backspace**는 마지막 점을 지웁니다.

| 도구 | 키 | 사용법 |
| --- | --- | --- |
| **선** | L | 점을 클릭하거나 길이와 각도를 입력합니다. CAD와 마찬가지로 각 선분은 독립된 객체가 됩니다. 첫 점을 클릭하면 닫힙니다. |
| **폴리라인** | (선 그룹) | 선과 같지만 모든 선분이 하나의 경로가 됩니다. 선 도구의 *모드* 칸에서 전환합니다. |
| **사각형** | R | 두 모서리를 클릭하거나 너비와 높이를 입력합니다. 첫 클릭 때 **Alt**를 누르면 중심에서부터 그립니다. *모서리 반지름*을 설정하면 둥근 모서리가 됩니다. |
| **정사각형** | (사각형 그룹) | *한 변*의 값 하나로 정하는 사각형입니다. |
| **원** | C | 중심을 클릭한 뒤 원둘레의 점을 클릭하거나 반지름을 입력합니다. |
| **세 점 원** | (원 그룹) | 원이 지나는 세 점을 클릭합니다. |
| **타원** | (원 그룹) | 중심, 첫 번째 축의 끝점을 클릭한 뒤 다른 반지름을 설정합니다. |
| **펜(곡선)** | P | 클릭하면 모서리 점, **드래그**하면 부드러운 곡선 점이 됩니다. 직선 가장자리는 길이와 각도를 입력합니다. 첫 점을 클릭하면 닫힙니다. |
| **호(세 점)** | A | 시작점, 끝점, 호가 지나는 점을 클릭합니다. |
| **중심선** | X | 도형을 클릭하면 그 가운데를 지나는 세로 또는 가로 중심선이 그려집니다. 두 점으로 그릴 수도 있습니다. 중심선은 대칭축으로 쓸 수 있습니다. |
| **수직선** | T | 직선 가장자리를 클릭한 뒤 직각으로 선을 놓습니다(또는 가장자리를 따라 거리와 길이를 입력합니다). |
| **평행선** | G | 직선 가장자리를 클릭한 뒤 쪽과 거리를 클릭하거나 거리를 입력합니다. |
| **라벨** | N | *텍스트* 모드: 글자가 시작될 위치를 클릭하고 입력(예: "앞판 · 2장 재단"), Enter. *결 방향 화살표* 모드: 양 끝을 클릭합니다. 라벨은 노트 레이어에 놓입니다. |

## 4. 도형 변경

### 변형

**이동, 회전, 배율, 대칭, 배열**은 선택한 객체에 적용됩니다. 아무것도 선택하지 않았다면 도구가 먼저 객체 선택을 요청합니다. 끝나면 **Enter**나 오른쪽 클릭을 누르세요. **원본 유지(복사)**를 체크하면 복사본을 변형합니다.

| 도구 | 키 | 단계 |
| --- | --- | --- |
| **이동** | M | 기준점 → 목표 지점, 또는 ΔX와 ΔY를 입력합니다. |
| **회전** | O | 중심 → 각도를 클릭하거나 입력합니다. Shift를 누르면 15° 단위로 맞춰집니다. |
| **배율** | S | 기준점(고정됨) → 배율을 입력하거나, 기준점과 그 점이 옮겨갈 위치를 클릭합니다. |
| **대칭** | I | 중심선을 클릭하면 그 선을 기준으로 대칭되고, 축 위의 두 점을 클릭하거나(한 점과 각도 입력) 할 수 있습니다. |
| **배열** | Q | *직선*: 기준점 → 다음 복사본이 놓일 위치. *개수*에는 원본이 포함됩니다. *원형*: 중심 → Enter. 360°이면 복사본을 고르게 배치하고, 그보다 작은 각도면 첫 복사본과 마지막 복사본 사이 각도로 펼칩니다. |
| **좌우 / 상하 뒤집기** | Shift+H / Shift+V | 선택 항목을 제자리에서 즉시 뒤집습니다. |

### 편집

| 도구 | 키 | 단계 |
| --- | --- | --- |
| **오프셋** | E | 경로, 원 또는 중심선을 클릭한 뒤 쪽을 클릭합니다. 거리는 커서를 따라가며, 직접 입력할 수도 있습니다. *모서리*: 날카롭게, 둥글게, 비스듬하게 중 선택합니다. 다시 클릭하면 계속 오프셋을 만들고, Esc를 누르면 원본을 다시 고를 수 있습니다. |
| **필렛** | F | 직선 두 개가 만나는 모서리에 커서를 올리고 클릭하면 둥글게 됩니다. **Shift+클릭**하면 도형의 모든 모서리가 둥글어집니다. 반지름을 입력해 바꿀 수 있으며, 너무 크면 안내 문구에 들어갈 수 있는 최대값이 표시됩니다. |
| **모따기** | B | 필렛과 비슷하지만 모서리를 직선으로 잘라냅니다. 두 거리 또는 거리와 각도를 입력합니다. |
| **자르기 / 연장 / 분할** | W | *자르기*: 제거할 선분을 클릭하면 가장 가까운 교차점까지 잘립니다. *연장*: 선의 끝 근처를 클릭하면 다음 선까지 늘어납니다. *분할*: 선을 클릭한 위치에서 나눕니다. Shift+클릭으로 자르기와 연장을 바꿉니다. |
| **경로 잇기** | Shift+J | 끝과 끝이 맞닿은 선택된 열린 경로들을 잇습니다. 끝이 만나는 하나의 경로는 닫힙니다. |
| **분해** | Shift+X | 선택한 사각형, 폴리라인, 외곽선을 개별 선분으로 나눕니다. |
| **합치기** | Shift+U | 선택한 닫힌 도형 둘 이상을 하나의 외곽선으로 합칩니다. |
| **차집합** | Shift+D | 가장 큰 도형에서 나머지 선택된 닫힌 도형을 빼냅니다. |

## 5. 가죽 전용 도구

LeatherDraft를 일반 CAD 프로그램과 구별해 주는 기능입니다. 결과물은 **서로 연결된 상태를 유지**합니다. 외곽선을 편집하면 스티치 선이 따라오고, 구멍은 스티치 선을 따라갑니다. 모든 것이 같은 실행 취소 단계로 함께 갱신됩니다.

### 스티치 선(K)

1. 외곽선을 클릭합니다.
2. 안쪽이나 바깥쪽을 클릭해 방향을 고릅니다. 여백은 프로젝트 설정(아래 참고)에서 가져오며, 다른 값을 직접 입력할 수도 있습니다.

스티치 선은 스티치 레이어에 그려지며, 이후 외곽선을 따라갑니다. 연결을 끊으려면 선을 선택하고 속성에서 **분리**를 누르세요.

### 스티치 구멍(H)

1. 입력 막대에서 옵션을 설정합니다.
   - 마름모 송곳의 **간격(피치)**: 2.7, 3.38, 3.85, 4.0, 5.0 mm 또는 **사용자 지정**.
   - **구멍 크기**와 **모양**: *원형* 또는 *사선 슬릿*(마름모 송곳처럼).
   - **모든 모서리에 구멍**: 각 변의 간격을 조정해 모든 모서리에 정확히 구멍이 위치하도록 합니다. 실제로 송곳을 따라 찍는 것과 같습니다.
2. 스티치 선(또는 임의의 선) 위에 커서를 올리면 구멍과 개수가 미리 보입니다.
3. 클릭해 추가합니다.

간격, 크기, 모양은 나중에 속성에서 바꿀 수 있습니다. **변별** 목록에서는 각 변의 구멍 개수를 확인할 수 있습니다.

### 프로젝트 기본값

아무것도 선택하지 않은 상태에서 속성의 **프로젝트** 섹션은 새 스티치 선과 구멍의 기본값을 정합니다. **스티치 여백**(3.5 mm), **간격**(3.85 mm), **구멍 크기**(1.2 mm)이며, 괄호 안이 기본값입니다.

### 시접(Y)

1. 닫힌 외곽선을 클릭합니다.
2. 모든 변에 적용할 값을 하나 입력하거나, 변을 클릭(여러 개는 Shift+클릭)한 뒤 그 변들에만 적용할 값을 입력합니다.
3. 아무것도 입력하지 않고 **Enter**를 누르면 시접 외곽선이 추가됩니다.

### 펀치 구멍 / 슬롯(U)

리벳, 스냅 단추, 나사 기둥, 버클 혀 등에 씁니다. *원형 구멍* 또는 *슬롯*을 고르고, 자주 쓰는 **펀치** 지름 또는 **사용자 지정**을 고른 뒤 클릭해 배치합니다(중심과 점에 스냅됩니다). 또는 X/Y를 입력하고 Enter를 누릅니다. 슬롯의 *길이*는 끝에서 끝까지이고, *너비*는 펀치 지름입니다.

### 노치(J)

조립할 때 맞추는 기준 표시입니다. *단일* 또는 *이중*, *절개(선)* 또는 *V 노치*를 고르고, 깊이(및 간격 / 너비)를 설정한 뒤 변을 클릭합니다. 노치는 부품 안쪽을 향하며, 열린 선에서는 커서가 있는 쪽을 향합니다.

### 선 종류

속성에서 경로의 **선 스타일**을 설정합니다. *실선(재단)*, *점선(접기 / 압인)*, *점선(참조)*, *일점쇄선(중심)* 중에서 고를 수 있습니다. **선 굵기(내보내기)**는 내보낸 파일에서 쓰는 선 두께를 정합니다.

## 6. 구속 조건

**구속 조건** 도구(Z)는 도형 사이의 관계를 정확하게 만듭니다. 어떤 경우든 **처음** 클릭한 것은 고정되고, **두 번째**로 클릭한 것이 움직입니다.

| 종류 | 클릭 |
| --- | --- |
| **평행** / **수직** | 직선 가장자리 두 개. |
| **접함** | 직선 가장자리 또는 원, 그다음 접하게 할 원(또는 가장자리). |
| **일치** | 두 점. |
| **거리** | 두 점을 클릭한 뒤 거리를 입력하고 Enter(Enter만 누르면 현재 값 유지). |
| **반지름** | 원을 클릭한 뒤 반지름을 입력하고 Enter. |

새 구속이 기존 구속과 충돌하면 아무것도 바뀌지 않으며, 안내 문구가 그 사실을 알려 줍니다.

선택한 객체의 구속 조건은 속성의 **구속 조건** 섹션에 나열됩니다. *미충족*으로 표시된 구속은 풀이 후에 도형이 움직였다는 뜻입니다. **풀기**를 누르면 복원됩니다. *깨짐*은 참조하던 대상이 바뀌었거나 삭제되었다는 뜻이며, × 버튼으로 삭제합니다.

## 7. 측정

**측정**(D)에는 네 가지 모드가 있습니다.

- **거리**: 두 점을 클릭합니다.
- **각도**: 한 점, 모서리 꼭짓점, 다른 한 점을 클릭합니다.
- **길이**: 도형 위에 커서를 올리면 길이가 보입니다.
- **구멍 개수**: 구멍 세트의 변을 클릭한 뒤, 바느질할 변을 클릭합니다. 안내 문구에 개수가 맞는지, 또는 구멍이 몇 개 차이 나는지 표시되므로 재단 전에 간격이나 변 길이를 조정할 수 있습니다.

## 8. 레이어와 속성

### 레이어

모든 도면에는 네 개의 레이어가 있습니다.

| 레이어 | 용도 |
| --- | --- |
| **재단** | 재단할 외곽선. |
| **스티치** | 스티치 선과 구멍. |
| **참조** | 보조선과 가져온 도면. |
| **노트** | 라벨과 결 방향 화살표. |

레이어마다 **표시 / 숨기기**(체크박스), **색상**(색 견본) 변경, **잠금 / 잠금 해제**(자물쇠)를 할 수 있습니다. 레이어 이름을 클릭하면 그 레이어에 **그릴 수 있습니다**. 잠기거나 숨겨진 레이어에는 그릴 수 없습니다.

### 속성

객체를 선택하면 위치, 너비와 높이, 길이, 반지름 또는 지름, 회전, 레이어, 선 스타일, 텍스트, 간격 등의 값을 보고 편집할 수 있습니다. 값을 입력하고 Enter를 누르세요. 여러 객체를 선택했을 때 값이 다르면 "—"로 표시되며, 값을 하나 입력하면 모두에 적용됩니다.

### 단위

상태 막대에서 **mm**, **cm**, **in** 중 하나를 고릅니다. 이는 화면 표시와 입력에만 영향을 주며, 도면은 항상 밀리미터 단위로 저장됩니다.

## 9. 파일

- **저장**(⌘/Ctrl+S)은 `.json` 프로젝트 파일로 기록합니다. **⌘/Ctrl+Shift+S**는 다른 이름으로 저장합니다.
- **열기…**(⌘/Ctrl+O)는 `.json` 프로젝트를 엽니다.
- **새로 만들기**는 빈 프로젝트를 시작합니다(저장하지 않은 변경 사항이 있으면 먼저 묻습니다).
- 프로젝트 이름은 도구 모음에 있습니다. 브라우저 탭 제목 앞의 점은 저장하지 않은 변경 사항이 있음을 뜻합니다.
- **가져오기…**는 **SVG 또는 DXF**를 실제 크기로 참조 레이어에 가져오고 선택 상태로 둡니다. 기존 패턴을 따라 그릴 때 유용합니다.
- **자동 저장**: 변경할 때마다 0.5초 후 작업 내용이 브라우저에 보관되며, 다음에 LeatherDraft를 열 때 복원됩니다. 자동 저장은 안전장치일 뿐 파일 저장을 대체하지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다.

**데스크톱 앱**: 저장, 열기, 내보내기는 시스템 파일 대화상자를 사용하며, 저장은 같은 파일에 계속 덮어씁니다.

**오프라인**: 한 번 불러오면 웹 앱은 오프라인에서도 동작합니다("오프라인 작업 준비 완료"). 새 버전이 나오면 **새로 고침**을 안내하는 알림이 나타납니다.

## 10. 내보내기와 인쇄

**내보내기…**는 내보내기 대화상자를 엽니다.

| 형식 | 용도 | 옵션 |
| --- | --- | --- |
| **PDF** | 1:1 인쇄 | 용지(A4, Letter, A3, 또는 대형 프린터용 **패턴 크기에 맞춘 한 페이지**), 방향(*최소 페이지*, 세로, 가로), 시트 간 겹침 |
| **SVG** | 레이저 커터, 커팅 플로터, Inkscape, Illustrator | 곡선을 짧은 직선으로 근사(곡선을 읽지 못하는 레이저 소프트웨어용) |
| **DXF** | 레이저 및 CNC 소프트웨어, mm 단위 | 도형만 포함하며 라벨은 제외 |
| **PNG** | 이미지 공유 | 해상도: 96, 150, 300 dpi. 패턴 제작용으로는 적합하지 않습니다. |

공통 옵션: **재단 레이어만(레이저)**, **라벨 포함**, **선 굵기**, **워터마크**(텍스트와 불투명도. PDF에서는 모든 페이지에 반복됩니다).

MCP 서버를 통해 AI가 만든 객체 중 아직 아무도 검토하지 않은 것이 도면에 있으면 대화상자가 경고합니다. 상태 막대에서 선택한 뒤 확인하고 속성에서 **검토 완료로 표시**를 누르세요.

### 실제 크기 인쇄

타일로 나뉜 PDF는 **조립 페이지**로 시작합니다. 시트 배치도와 **50 mm 보정 정사각형**이 들어 있습니다. 각 시트에는 재단 표시와 라벨(A1, A2, B1…)이 있습니다.

1. **100 % / "실제 크기"**로 인쇄합니다. "페이지에 맞춤"이나 "큰 페이지 축소"는 사용하지 마세요.
2. **50 mm 정사각형을 재어 보세요.** 정확히 50 mm가 아니면 프린터 배율 설정을 고친 뒤 다시 인쇄합니다.
3. 점선을 따라 자르거나 시트를 겹쳐서, 모서리 표시와 시트 라벨을 맞춘 뒤 테이프로 붙입니다.

## 12. 실습: 카드 지갑 만들기

1. **사각형**(R): 한 번 클릭하고 `95`, Tab, `65`, Enter를 입력합니다. 재단 레이어에 95 × 65 mm 부품이 생깁니다.
2. **필렛**(F): `5`를 입력한 뒤 모서리 하나를 **Shift+클릭**하면 네 모서리가 모두 둥글어집니다.
3. **스티치 선**(K): 외곽선을 클릭한 다음 안쪽을 클릭합니다. 기본 여백이면 가장자리에서 3.5 mm 안쪽에 스티치 선이 생깁니다.
4. **스티치 구멍**(H): 간격 **3.85**를 고르고 **모든 모서리에 구멍**을 체크한 뒤, 스티치 선 위에 커서를 올리고 클릭합니다.
5. **라벨**(N): 부품 안쪽을 클릭하고 `카드 지갑 · 2장 재단`을 입력한 뒤 Enter.
6. 외곽선을 바꿔 보세요. 사각형을 선택하고 속성에서 **너비**를 `100`으로 설정합니다. 스티치 선과 구멍이 따라갑니다.
7. **저장**(⌘/Ctrl+S)하고, **내보내기…** → PDF → A4 → 100 %로 인쇄한 뒤 50 mm 정사각형을 재어 봅니다.

## 13. 문제 해결

| 문제 | 해결 방법 |
| --- | --- |
| 아무것도 그려지지 않음 / "현재 레이어가 잠겨 있거나 숨겨져 있습니다" | 레이어를 잠금 해제하거나 표시하거나, 레이어 패널에서 다른 레이어를 고르세요. |
| 인쇄물이 약간 작거나 큼 | PDF의 배율이 바뀌었습니다. 100 % / 실제 크기로 인쇄하고 50 mm 정사각형을 다시 확인하세요. |
| 필렛에 "이 모서리에는 너무 큽니다"라고 표시됨 | 안내에 나온 최대 반지름을 쓰거나 변을 길게 하세요. |
| 꿰맬 두 변의 구멍 개수가 맞지 않음 | 측정 → 구멍 개수를 사용해 간격이나 한 변의 길이를 조정하세요. |
| 구속 조건 "충돌" | 새 구속이 기존 구속과 모순됩니다. 속성 → 구속 조건에서 하나를 삭제하세요. |
| 레이저 소프트웨어에서 곡선이 끊어져 보임 | **곡선을 짧은 직선으로 근사**를 켜고 SVG로 내보내거나, DXF를 사용하세요. |
| 도구 단축키가 반응하지 않음 | 텍스트 입력 칸에 포커스가 있을 수 있습니다. 먼저 작업 영역을 클릭하세요. 키가 다른 기능으로 바뀌었는지 **단축키…**에서 확인하세요. |
