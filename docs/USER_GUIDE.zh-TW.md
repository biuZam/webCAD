# LeatherDraft 操作手冊

[English](USER_GUIDE.md) · [简体中文](USER_GUIDE.zh-CN.md) · **繁體中文** · [Deutsch](USER_GUIDE.de.md) · [Français](USER_GUIDE.fr.md) · [Español](USER_GUIDE.es.md) · [Italiano](USER_GUIDE.it.md) · [Português](USER_GUIDE.pt.md) · [日本語](USER_GUIDE.ja.md) · [한국어](USER_GUIDE.ko.md)

LeatherDraft 是一款用於繪製皮件版型的二維製圖工具。以毫米為單位繪圖，依 1:1 實際尺寸列印或裁切。它在瀏覽器中執行（也有桌面版），不需註冊帳號，檔案只保存在您自己的裝置上。

## 2. 基本操作

### 選取

使用**選取**工具（V）：

- 點擊物件即可選取；**Shift+點擊**可加選或減選。
- **從左至右**拖曳框選，選取完全在框內的物件；**從右至左**拖曳框選，選取所有被框碰到的物件。
- **拖曳**已選取的物件即可移動；拖曳時按住 **Alt** 可移動一個複本。
- **Delete** 刪除所選物件。**⌘/Ctrl+A** 全選。**Esc** 取消選取。

**編輯節點。** 選取一個圖形後，會顯示它的節點與貝茲控制柄：

- 拖曳節點或控制柄即可移動。
- **雙擊節點**，可在平滑與尖角之間切換。
- **雙擊輪廓**，可新增節點。
- 點擊一個節點後按 **Delete**，可刪除該節點。

### 輸入精確數值

所有繪圖與編輯工具都可以輸入數值。**直接開始打數字**，數字會進入輸入列。

- **Tab** 切換到下一個欄位（例如 長度 → 角度，或 X → Y）。
- **Enter** 確認，**Esc** 清除。
- 長度使用狀態列中選定的顯示單位（mm、cm 或 in）。角度以度為單位，自 +X 方向起逆時針計算。

繪圖時按住 **Shift**，可將角度鎖定為 15° 的倍數。

### 鎖點

游標會自動鎖定到既有的幾何圖形。在狀態列開啟**鎖點**選單，可分別開關各類鎖點：

端點 · 中點 · 圓心 · 象限點 · 交點 · 垂足 · 切點 · 最近點 · 格線 · 極座標追蹤（45°）· 物件追蹤

游標處的標記會顯示目前生效的鎖點類型。

### 檢視操作

- **滑鼠滾輪**或觸控板雙指縮放：以游標為中心縮放。
- **按住空白鍵拖曳**或**按住中鍵拖曳**：平移。
- 縮放比例顯示在狀態列；100% 時 1 mm 顯示為 96/25.4 個 CSS 像素（名目上的實際大小）。

### 復原

**⌘/Ctrl+Z** 復原，**⇧⌘Z / Ctrl+Shift+Z**（或 Ctrl+Y）重做。每個操作恰好是一個復原步驟，包括它連帶更新的縫線與縫孔。同一工作階段內的復原次數不限。

## 3. 繪圖工具

新圖形會畫在**作用中圖層**上（見[圖層](#8-圖層與屬性)）。大多數工具以 **Enter、雙擊或右鍵**結束圖形，**Backspace** 會撤回最後一個節點。

| 工具 | 快捷鍵 | 用法 |
| --- | --- | --- |
| **直線** | L | 依序點擊各點，或輸入長度與角度。與 CAD 一樣，每一段都是獨立的物件。點擊第一個點即可封閉。 |
| **多段線** | （直線群組） | 與直線相同，但所有線段組成一條路徑。在直線工具的*模式*欄位中切換。 |
| **矩形** | R | 點擊兩個角點，或輸入寬度與高度。第一次點擊時按住 **Alt** 可從中心繪製。設定*圓角半徑*即可得到圓角矩形。 |
| **正方形** | （矩形群組） | 只需一個*邊長*的矩形。 |
| **圓形** | C | 點擊圓心，再點擊圓上一點，或輸入半徑。 |
| **三點圓** | （圓形群組） | 依序點擊圓通過的三個點。 |
| **橢圓** | （圓形群組） | 點擊中心、第一軸的端點，然後設定另一個半徑。 |
| **筆（曲線）** | P | 點擊建立尖角節點，**拖曳**建立平滑曲線節點。輸入長度與角度可畫直邊。點擊第一個點即可封閉。 |
| **圓弧（三點）** | A | 依序點擊起點、終點，以及圓弧通過的一點。 |
| **中心線** | X | 點擊一個圖形，會在其中心畫出垂直或水平的中心線；也可用兩點繪製。中心線可作為鏡射軸。 |
| **垂線** | T | 點擊一條直邊，再放置與之垂直的線（或輸入沿邊距離與長度）。 |
| **平行線** | G | 點擊一條直邊，再點擊所在的一側與距離，或輸入距離。 |
| **標註** | N | *文字*模式：點擊文字起點，輸入文字（例如「前片 · 裁 2 片」），按 Enter。*紋理方向箭頭*模式：點擊兩端。標註放在「備註」圖層。 |

## 4. 修改圖形

### 變形

**移動、旋轉、縮放、鏡射**與**陣列**作用於所選物件。若未選取任何物件，工具會先要求您選取；完成後按 **Enter** 或右鍵。勾選**保留原物件（複本）**可對複本進行變形。

| 工具 | 快捷鍵 | 步驟 |
| --- | --- | --- |
| **移動** | M | 基準點 → 目標點，或輸入 ΔX 與 ΔY。 |
| **旋轉** | O | 旋轉中心 → 點擊角度，或直接輸入。Shift 會以 15° 為單位取整。 |
| **縮放** | S | 基準點（保持不動）→ 輸入比例；或點擊參考點，再點擊它的目標位置。 |
| **鏡射** | I | 點擊一條中心線以其為軸鏡射；或點擊軸線上的兩點（或一點再輸入軸線角度）。 |
| **陣列** | Q | *線性*：基準點 → 下一個複本的位置；*數量*包含原物件。*環形*：中心 → Enter；360° 時複本平均分布一圈，小於 360° 時首尾複本跨越該角度。 |
| **水平翻轉 / 垂直翻轉** | Shift+H / Shift+V | 原地立即翻轉所選物件。 |

### 編輯

| 工具 | 快捷鍵 | 步驟 |
| --- | --- | --- |
| **偏移** | E | 點擊路徑、圓或中心線，再點擊偏移的一側。距離跟隨游標，也可直接輸入。*角*：銳角、圓角或斜切。再次點擊可繼續偏移；按 Esc 重新選擇來源。 |
| **圓角** | F | 將滑鼠移到兩條直邊之間的角上，點擊即可倒圓角。**Shift+點擊**可為圖形的所有角倒圓角。輸入半徑即可修改；半徑過大時，提示會給出可容納的最大半徑。 |
| **倒角** | B | 與圓角類似，但將角切成直線。輸入兩個距離，或一個距離與一個角度。 |
| **修剪 / 延伸 / 打斷** | W | *修剪*：點擊要刪除的線段，修剪到最近的交點。*延伸*：點擊線的端點附近，延伸到遇到的下一條線。*打斷*：點擊線，在該點切開。Shift+點擊可在修剪與延伸之間切換。 |
| **接合路徑** | Shift+J | 將首尾相接的已選取開放路徑接合為一條；一條首尾相接的路徑則會被封閉。 |
| **分解** | Shift+X | 將所選矩形、多段線或輪廓拆成獨立的線段。 |
| **聯集** | Shift+U | 將兩個或更多已選取的封閉圖形合併為一個輪廓。 |
| **差集** | Shift+D | 用其餘已選取的封閉圖形，從最大的那個中挖去。 |

## 5. 皮革專用工具

這些工具是 LeatherDraft 與一般 CAD 軟體的區別所在。產生的結果**保持關聯**：修改輪廓，縫線會跟著變；縫孔則跟隨縫線。所有更新都在同一個復原步驟內完成。

### 縫線（K）

1. 點擊一個輪廓。
2. 點擊內側或外側以決定方向。邊距取自專案設定（見下文），也可以輸入其他數值。

縫線會畫在「縫線」圖層上，之後會一直跟隨其輪廓。要解除關聯，請選取縫線後，在屬性面板中按**解除關聯**。

### 縫孔（H）

1. 在輸入列中設定選項：
   - **菱斬**的孔距（間距）：2.7、3.38、3.85、4.0 或 5.0 mm，或**自訂**。
   - **孔徑**與**形狀**：*圓孔*或*斜孔（菱斬）*。
   - **每個角都打孔**：每條邊的間距會被均分，使每個角上正好有一個孔，就像實際用菱斬走線一樣。
2. 將滑鼠移到縫線（或任意線）上，即可預覽縫孔與其數量。
3. 點擊即可加入。

之後可在屬性面板中修改孔距、孔徑或形狀；**每邊孔數**會列出每條邊上的孔數。

### 專案預設值

未選取任何物件時，屬性面板中的**專案**區段可設定新縫線與縫孔的預設值：**縫線邊距**（3.5 mm）、**孔距**（3.85 mm）與**孔徑**（1.2 mm），括號內為預設值。

### 縫份（Y）

1. 點擊一個封閉輪廓。
2. 輸入一個數值套用到所有邊；或點擊某些邊（Shift+點擊可多選），只為這些邊輸入數值。
3. 未輸入任何數值時按 **Enter**，即可加入縫份輪廓。

### 沖孔 / 長孔（U）

用於鉚釘、四合扣、螺絲柱與皮帶扣舌。選擇*圓孔*或*長孔*，挑選常用的**沖頭**直徑或**自訂**，然後點擊放置（會自動對齊圓心與端點），或輸入 X/Y 後按 Enter。長孔的*長度*為兩端總長，*寬度*即沖頭直徑。

### 對位刀口（J）

用於組裝時對位的標記。選擇*單刀*或*雙刀*，以及*切口（直線）*或 *V 形刀口*，設定深度（與間距 / 寬度），然後點擊一條邊。刀口朝向零件內側；在開放線上則朝向游標所在的一側。

### 線型

在屬性面板中設定路徑的**線型**：*實線（裁切）*、*虛線（摺線 / 壓痕）*、*點線（參考）*或*點劃線（中心線）*。**線寬（匯出）**設定匯出檔案時使用的線寬。

## 6. 約束

**約束**工具（Z）可讓圖形之間的關係精確無誤。每種約束中，**先**點擊的物件保持不動，**後**點擊的物件會移動。

| 類型 | 點擊 |
| --- | --- |
| **平行** / **垂直** | 兩條直邊。 |
| **相切** | 一條直邊或一個圓，再點擊要與之相切的圓（或直邊）。 |
| **重合** | 兩個點。 |
| **距離** | 兩個點，然後輸入距離並按 Enter（只按 Enter 會保留目前的值）。 |
| **半徑** | 一個圓，然後輸入半徑並按 Enter。 |

若新約束與既有約束衝突，不會有任何變更，提示會說明此情況。

選取的物件會在屬性面板的**約束**區段列出其約束。標示為*未滿足*表示求解後圖形又被移動過，按**求解**即可恢復。標示為*已損壞*表示其參照的對象已被修改或刪除，請用 × 按鈕刪除。

## 7. 量測

**量測**（D）有四種模式：

- **距離**：點擊兩點。
- **角度**：依序點擊一點、角點與另一點。
- **長度**：將滑鼠移到圖形上，即可看到其長度。
- **孔數**：點擊一組縫孔的一條邊，再點擊要縫合的另一條邊。提示會告訴您孔數是否相符，或相差幾個孔，方便您在裁切前調整孔距或邊長。

## 8. 圖層與屬性

### 圖層

每份圖面都有四個圖層：

| 圖層 | 用途 |
| --- | --- |
| **裁切** | 需要裁切的輪廓。 |
| **縫線** | 縫線與縫孔。 |
| **參考** | 輔助線與匯入的圖形。 |
| **備註** | 標註與紋理方向箭頭。 |

每個圖層都可以**顯示 / 隱藏**（核取方塊）、變更**顏色**（色塊）、**鎖定 / 解鎖**（鎖頭按鈕），點擊圖層名稱即可**在該圖層上繪圖**。已鎖定或已隱藏的圖層無法繪圖。

### 屬性

選取物件即可查看與編輯其數值：位置、寬與高、長度、半徑或直徑、旋轉、圖層、線型、文字、孔距等。輸入數值後按 Enter。選取多個物件時，數值不同的項目會顯示為「—」；輸入一個新值會同時套用到所有物件。

### 單位

在狀態列中選擇 **mm**、**cm** 或 **in**。這只會影響顯示與輸入，圖面一律以毫米儲存。

## 9. 檔案

- **儲存**（⌘/Ctrl+S）會寫入 `.json` 專案檔。**⌘/Ctrl+Shift+S** 可另存新檔。
- **開啟…**（⌘/Ctrl+O）開啟 `.json` 專案。
- **新增**會建立空白專案（若有未儲存的變更，會先詢問）。
- 專案名稱位於工具列；瀏覽器分頁標題前的圓點表示有未儲存的變更。
- **匯入…**可將 **SVG 或 DXF** 以實際尺寸匯入到「參考」圖層，並自動選取，方便描摹既有版型。
- **自動儲存**：每次變更後半秒，您的作品會保存在瀏覽器中，下次開啟 LeatherDraft 時自動還原。自動儲存只是安全網，不能取代儲存檔案：清除瀏覽器資料會將其刪除。

**桌面版**：儲存、開啟與匯出會使用系統的檔案對話框，儲存時會持續寫入同一個檔案。

**離線使用**：網頁版載入一次後即可離線使用（提示「已可離線工作」）。有新版本時，會出現**重新載入**的提示。

## 10. 匯出與列印

點擊**匯出…**開啟匯出對話框。

| 格式 | 用途 | 選項 |
| --- | --- | --- |
| **PDF** | 以 1:1 列印 | 紙張（A4、Letter、A3，或供大幅面印表機使用的**依版型尺寸的單頁**）、方向（*頁數最少*、直向、橫向）、頁面之間的重疊 |
| **SVG** | 雷射切割機、刻字機、Inkscape、Illustrator | 曲線以短直線近似（供無法讀取曲線的雷射軟體使用） |
| **DXF** | 雷射與 CNC 軟體，單位為毫米 | 只包含圖形：標註會被略過 |
| **PNG** | 分享圖片 | 解析度：96、150 或 300 dpi。不適合用來製作版型。 |

常用選項：**僅裁切圖層（雷射）**、**包含標註**、**線寬**，以及**浮水印**（文字與透明度；在 PDF 中會在每一頁重複出現）。

若圖面中有由 AI（透過 MCP 伺服器）建立、但尚未經人工檢視的物件，對話框會發出提醒。請從狀態列選取它們，檢查後在屬性面板中按**標記為已檢視**。

### 依實際尺寸列印

分頁的 PDF 首頁是**組裝頁**：包含各頁的拼接示意圖與一個 **50 mm 校準方塊**。每一頁都有裁切標記與頁面標籤（A1、A2、B1…）。

1. 以 **100% /「實際大小」**列印。切勿選擇「符合頁面」或「縮小超大頁面」。
2. **量測 50 mm 方塊。** 若不是剛好 50 mm，請修正印表機的縮放設定後重新列印。
3. 沿虛線裁切，或將各頁重疊，對齊角落標記與頁面標籤，然後用膠帶黏合。

## 12. 實例：繪製一個卡夾

1. **矩形**（R）：點擊一次，輸入 `95`，Tab，`65`，Enter。「裁切」圖層上就會有一個 95 × 65 mm 的零件。
2. **圓角**（F）：輸入 `5`，然後 **Shift+點擊**任一角，四個角全部倒圓角。
3. **縫線**（K）：點擊輪廓，再點擊內側。使用預設邊距時，縫線會位於輪廓內側 3.5 mm 處。
4. **縫孔**（H）：選擇孔距 **3.85**，勾選**每個角都打孔**，將滑鼠移到縫線上並點擊。
5. **標註**（N）：在零件內點擊，輸入 `卡夾 · 裁 2 片`，按 Enter。
6. 試著修改輪廓：選取矩形，在屬性面板中將**寬**改為 `100`。縫線與縫孔會跟著更新。
7. **儲存**（⌘/Ctrl+S），然後 **匯出…** → PDF → A4 → 以 100% 列印，並量測 50 mm 方塊。

## 13. 常見問題

| 問題 | 解決方法 |
| --- | --- |
| 無法繪圖 /「作用中圖層已鎖定或隱藏」 | 解鎖或顯示該圖層，或在「圖層」面板中選擇其他圖層。 |
| 列印出來略大或略小 | PDF 被縮放了。請以 100% /「實際大小」列印，並重新量測 50 mm 方塊。 |
| 圓角提示「對此角而言過大」 | 使用提示中給出的最大半徑，或加長邊。 |
| 要縫合的兩條邊孔數不一致 | 使用 量測 → 孔數 檢查，然後調整孔距或其中一條邊的長度。 |
| 約束提示「衝突」 | 新約束與既有約束互相矛盾。在 屬性 → 約束 中刪除其中一個。 |
| 雷射軟體顯示的曲線斷裂 | 匯出 SVG 時勾選**曲線以短直線近似**，或改用 DXF。 |
| 工具快捷鍵沒有反應 | 可能有文字欄位取得焦點：先點擊畫布。請在**快捷鍵…**中確認該按鍵沒有被重新指定。 |
