LeatherDraft は革小物の型紙を描くための 2D 製図ツールです。ミリメートル単位で描き、1:1 の実寸で印刷または裁断できます。ブラウザ（またはデスクトップアプリ）で動作し、アカウントは不要で、ファイルはお使いの端末に保存されます。

## 1. 画面

| 領域 | 内容 |
| --- | --- |
| **ツールバー**（上部） | プロジェクト名、新規、開く…、保存、読み込み…、書き出し…、元に戻す / やり直し、ショートカット…、言語 |
| **ツールパレット**（左） | すべてのツールをグループ別に配置。右下に小さな三角のあるボタンには複数のツールが入っています。**右クリック**（長押し、またはフォーカス中に → キー）で別のツールを選べます。ボタンは最後に使ったツールを覚えます。 |
| **作図エリア**（中央） | ミリメートル単位で、グリッド付きのキャンバス。ツールの案内や数値入力用の**入力バー**はここに表示されます。 |

## 2. 基本操作

### 選択

**選択**ツール（V）を使います。

- オブジェクトをクリックして選択します。**Shift+クリック**で追加・解除できます。
- **左から右**へドラッグすると、枠内に完全に含まれるオブジェクトを選択します。**右から左**へドラッグすると、枠に触れるものすべてを選択します。
- 選択したオブジェクトを**ドラッグ**すると移動します。**Alt** を押しながらドラッグするとコピーを移動します。
- **Delete** で選択を削除します。**⌘/Ctrl+A** ですべて選択。**Esc** で選択解除。

**点の編集。** 図形を一つ選択すると、その点とベジェのハンドルが表示されます。

- 点やハンドルをドラッグして動かします。
- **点をダブルクリック**すると、滑らかな点と角の点を切り替えられます。
- **輪郭をダブルクリック**すると、点を追加できます。
- 点をクリックしてから **Delete** を押すと、その点を削除します。

### 正確な数値の入力

作図・編集のすべてのツールは数値入力に対応しています。**数字を打つだけで**、入力バーに入ります。

- **Tab** で次の入力欄へ移動します（例：長さ → 角度、X → Y）。
- **Enter** で確定、**Esc** でクリアします。
- 長さはステータスバーで選んだ表示単位（mm、cm、in）で入力します。角度は度数法で、+X 方向から反時計回りです。

作図中に **Shift** を押し続けると、角度が 15° 刻みに固定されます。

### スナップ

カーソルは既存の図形にスナップします。ステータスバーの**スナップ**を開くと、種類ごとに on/off できます。

端点 · 中点 · 中心 · 象限点 · 交点 · 垂線 · 接点 · 最近点 · グリッド · 極トラッキング（45°） · オブジェクトトラッキング

カーソル上のマーカーで、現在有効なスナップが分かります。

### 表示の移動

- **マウスホイール**またはトラックパッドのピンチ：カーソル位置を中心にズームします。
- **Space + ドラッグ**または**中ボタンのドラッグ**：表示を移動します。
- ズーム倍率はステータスバーにあります。100 % のとき 1 mm は 96/25.4 CSS ピクセルで描かれます（名目上の実寸）。

### 元に戻す

**⌘/Ctrl+Z** で元に戻し、**⇧⌘Z / Ctrl+Shift+Z**（または Ctrl+Y）でやり直します。操作は一つずつ戻せます。連動して更新される縫い線や穴も同じ一手として扱われます。セッション中は無制限に戻せます。

## 3. 作図ツール

新しい図形は**現在のレイヤー**に作成されます（[レイヤー](#8-レイヤーとプロパティ)を参照）。多くのツールは **Enter、ダブルクリック、右クリック**で図形を確定し、**Backspace** で最後の点を取り消します。

| ツール | キー | 使い方 |
| --- | --- | --- |
| **直線** | L | 点をクリックするか、長さと角度を入力します。CAD と同じく、各線分は独立したオブジェクトになります。最初の点をクリックすると閉じます。 |
| **ポリライン** | （直線グループ） | 直線と同じですが、すべての線分が一つのパスになります。直線ツールの*モード*欄で切り替えます。 |
| **長方形** | R | 二つの角をクリックするか、幅と高さを入力します。最初のクリックで **Alt** を押すと中心から描きます。*角丸半径*を設定すると角が丸くなります。 |
| **正方形** | （長方形グループ） | *辺の長さ*一つで指定する長方形です。 |
| **円** | C | 中心をクリックし、円周上の点をクリックするか、半径を入力します。 |
| **3 点円** | （円グループ） | 円が通る三点をクリックします。 |
| **楕円** | （円グループ） | 中心、最初の軸の端点をクリックし、もう一方の半径を指定します。 |
| **ペン（曲線）** | P | クリックで角の点、**ドラッグ**で滑らかな曲線の点を置きます。直線の辺は長さと角度を入力します。最初の点をクリックすると閉じます。 |
| **円弧（3 点）** | A | 始点、終点、円弧が通る点をクリックします。 |
| **中心線** | X | 図形をクリックすると、その中央に縦または横の中心線を引きます。二点から引くこともできます。中心線は対称軸として使えます。 |
| **垂線** | T | 直線の辺をクリックし、直角に線を置きます（または辺に沿った距離と長さを入力します）。 |
| **平行線** | G | 直線の辺をクリックし、側と距離をクリックするか、距離を入力します。 |
| **ラベル** | N | *テキスト*モード：文字の開始位置をクリックし、入力（例：「前身頃 · 2 枚裁断」）、Enter。*革目矢印*モード：両端をクリックします。ラベルはノートレイヤーに置かれます。 |

## 4. 図形の変更

### 変形

**移動、回転、拡大縮小、鏡像、配列**は選択中のオブジェクトに作用します。何も選択していない場合、ツールはまずオブジェクトの選択を求めます。終わったら **Enter** か右クリックを押します。**元のオブジェクトを残す（コピー）**にチェックを入れると、コピーを変形します。

| ツール | キー | 手順 |
| --- | --- | --- |
| **移動** | M | 基点 → 移動先、または ΔX と ΔY を入力します。 |
| **回転** | O | 中心 → 角度をクリックするか入力します。Shift で 15° 単位に丸めます。 |
| **拡大縮小** | S | 基点（固定される点）→ 倍率を入力するか、基準点とその移動先をクリックします。 |
| **鏡像** | I | 中心線をクリックするとその線を軸に反転します。または軸上の二点をクリックします（一点と角度入力でも可）。 |
| **配列** | Q | *直線状*：基点 → 次のコピーの位置。*個数*は元のオブジェクトを含みます。*円状*：中心 → Enter。360° では等間隔に配置し、それより小さい角度では最初と最後のコピーの間をその角度で広げます。 |
| **左右 / 上下反転** | Shift+H / Shift+V | 選択を、その場で即座に反転します。 |

### 編集

| ツール | キー | 手順 |
| --- | --- | --- |
| **オフセット** | E | パス、円、中心線をクリックしてから、側をクリックします。距離はカーソルに追従し、入力もできます。*角*：シャープ、丸め、面取りから選べます。もう一度クリックすると続けてオフセットできます。Esc で別の元図形を選べます。 |
| **フィレット** | F | 直線二本の間の角にカーソルを合わせてクリックすると、角が丸くなります。**Shift+クリック**で図形のすべての角を丸めます。半径を入力すると変更できます。大きすぎる場合は、入る最大値を案内に表示します。 |
| **面取り** | B | フィレットと同様ですが、角を直線で切り落とします。二つの距離、または距離と角度を入力します。 |
| **トリム / 延長 / 分割** | W | *トリム*：削除する線分をクリックします（最も近い交点まで）。*延長*：線の端付近をクリックすると、次の線まで延長します。*分割*：線をクリックした位置で切断します。Shift+クリックでトリムと延長を入れ替えます。 |
| **パスの結合** | Shift+J | 端同士が接している開いたパスを結合します。端が一致する単一のパスは閉じられます。 |
| **分解** | Shift+X | 選択した長方形、ポリライン、輪郭を個別の線分に分解します。 |
| **和** | Shift+U | 選択した二つ以上の閉じた図形を一つの輪郭にまとめます。 |
| **差** | Shift+D | 最も大きい図形から、他の選択した閉じた図形を切り抜きます。 |

## 5. レザー専用ツール

これが LeatherDraft が一般的な CAD と異なる点です。結果は**連動したまま**です。輪郭を編集すると縫い線が追従し、穴は縫い線に追従します。すべて同じ元に戻す操作にまとめられます。

### 縫い線（K）

1. 輪郭をクリックします。
2. 内側または外側をクリックして側を選びます。余白はプロジェクト設定の値（後述）になりますが、別の値を入力することもできます。

縫い線はステッチレイヤーに描かれ、以後は輪郭に追従します。連動を解除するには、縫い線を選択してプロパティの**切り離し**を押します。

### 縫い穴（H）

1. 入力バーでオプションを設定します。
   - **菱目打ち**のピッチ：2.7、3.38、3.85、4.0、5.0 mm、または**カスタム**。
   - **穴の大きさ**と**形状**：*丸穴*または*斜めスリット*（菱目打ちのような形）。
   - **すべての角に穴**：各辺の間隔を調整し、目打ちを通すときのように、どの角にも必ず穴が入るようにします。
2. 縫い線（または任意の線）の上にカーソルを置くと、穴と個数をプレビューできます。
3. クリックして追加します。

ピッチ、大きさ、形状はあとからプロパティで変更できます。**辺ごと**の一覧で、各辺の穴の数が分かります。

### プロジェクトの既定値

何も選択していないとき、プロパティの**プロジェクト**セクションで、新しい縫い線と穴の既定値を設定できます。**縫い代**（3.5 mm）、**ピッチ**（3.85 mm）、**穴の大きさ**（1.2 mm）で、括弧内が既定値です。

### 縫い代（Y）

1. 閉じた輪郭をクリックします。
2. すべての辺に一つの値を入力するか、辺をクリックして（複数は Shift+クリック）、それらの辺だけに値を入力します。
3. 何も入力せずに **Enter** を押すと、縫い代の輪郭が追加されます。

### 打ち抜き穴 / 長穴（U）

リベット、スナップボタン、ねじ足、バックルの舌などに使います。*丸穴*または*長穴*を選び、よく使う**パンチ**の直径または**カスタム**を選択してから、クリックして配置します（中心と点に吸着します）。あるいは X/Y を入力して Enter を押します。長穴の場合、*長さ*は端から端まで、*幅*はパンチの直径です。

### 合い印（J）

組み立て時の位置合わせのための印です。*単一*または*二重*、*切り込み（線）*または *V 字*を選び、深さ（および間隔 / 幅）を設定してから、辺をクリックします。合い印は部材の内側に向きます。開いた線では、カーソルのある側に向きます。

### 線種

プロパティで、パスの**線種**を設定します。*実線（裁断）*、*破線（折り / 筋入れ）*、*点線（参考）*、*一点鎖線（中心）*から選べます。**線幅（書き出し）**は書き出すファイルの線の太さを設定します。

## 6. 拘束

**拘束**ツール（Z）は図形間の関係を正確にします。どの場合も、**最初**にクリックしたものは動かず、**二番目**にクリックしたものが動きます。

| 種類 | クリックするもの |
| --- | --- |
| **平行** / **垂直** | 直線の辺二本。 |
| **接線** | 直線の辺または円、次に接線にする円（または辺）。 |
| **一致** | 二つの点。 |
| **距離** | 二つの点をクリックし、距離を入力して Enter（Enter だけなら現在の値を維持します）。 |
| **半径** | 円をクリックし、半径を入力して Enter。 |

新しい拘束が既存の拘束と矛盾する場合、何も変わらず、その旨が案内に表示されます。

選択したオブジェクトは、プロパティの**拘束**セクションに拘束を一覧表示します。*未充足*と表示された拘束は、解決後に図形が動かされたことを意味します。**解決**を押すと元に戻ります。*無効*は、参照先が変更または削除されたことを意味します。× ボタンで削除してください。

## 7. 計測

**計測**（D）には四つのモードがあります。

- **距離**：二つの点をクリックします。
- **角度**：一点、角の頂点、もう一点をクリックします。
- **長さ**：図形にカーソルを合わせると長さが表示されます。
- **穴数**：穴のセットの辺をクリックし、次に縫い合わせる辺をクリックします。案内に、穴数が一致しているか、何個ずれているかが表示されます。裁断前にピッチや辺の長さを調整できます。

## 8. レイヤーとプロパティ

### レイヤー

すべての図面には四つのレイヤーがあります。

| レイヤー | 用途 |
| --- | --- |
| **裁断** | 裁断する輪郭。 |
| **ステッチ** | 縫い線と穴。 |
| **参考** | 補助線と読み込んだ図面。 |
| **ノート** | ラベルと革目矢印。 |

レイヤーごとに、**表示 / 非表示**（チェックボックス）、**色**（カラーチップ）の変更、**ロック / ロック解除**（錠前アイコン）ができます。また、名前をクリックすると**そのレイヤーに描画**できます。ロックされている、または非表示のレイヤーには描けません。

### プロパティ

オブジェクトを選択すると、位置、幅と高さ、長さ、半径または直径、回転、レイヤー、線種、テキスト、ピッチなどを確認・編集できます。値を入力して Enter を押します。複数のオブジェクトを選択すると、値が異なる項目は「—」と表示されます。一つの値を入力すると、すべてに適用されます。

### 単位

ステータスバーで **mm**、**cm**、**in** を選びます。これは表示と入力だけを変えます。図面は常にミリメートルで保存されます。

## 9. ファイル

- **保存**（⌘/Ctrl+S）で `.json` のプロジェクトファイルを書き出します。**⌘/Ctrl+Shift+S** で名前を付けて保存します。
- **開く…**（⌘/Ctrl+O）で `.json` のプロジェクトを開きます。
- **新規**で空のプロジェクトを始めます（未保存の変更がある場合は確認します）。
- プロジェクト名はツールバーにあります。ブラウザのタブのタイトルにある点は、未保存の変更があることを示します。
- **読み込み…**で **SVG または DXF** を実寸で参考レイヤーに取り込み、選択された状態にします。既存の型紙をトレースできます。
- **自動保存**：変更のたびに、0.5 秒後にブラウザ内へ作業内容が保存され、次に LeatherDraft を開いたときに復元されます。自動保存は安全装置であり、ファイルの保存の代わりにはなりません。ブラウザのデータを消去すると失われます。

**デスクトップアプリ**：保存、開く、書き出しはシステムのファイルダイアログを使い、保存は同じファイルに上書きし続けます。

**オフライン**：一度読み込めば、Web 版はオフラインで動作します（「オフラインで作業できます」）。新しいバージョンがあると、**再読み込み**の通知が表示されます。

## 10. 書き出しと印刷

**書き出し…**で書き出しダイアログを開きます。

| 形式 | 用途 | オプション |
| --- | --- | --- |
| **PDF** | 1:1 での印刷 | 用紙（A4、Letter、A3、または大判プリンター向けの**型紙に合わせた一枚の用紙**）、向き（*ページ数を最小に*、縦、横）、用紙同士の重なり |
| **SVG** | レーザー加工機、カッティングプロッター、Inkscape、Illustrator | 曲線を短い直線で近似（曲線を読めないレーザーソフト向け） |
| **DXF** | レーザーや CNC のソフト、単位は mm | 図形のみ。ラベルは含みません。 |
| **PNG** | 画像の共有 | 解像度：96、150、300 dpi。型紙の作成には使えません。 |

共通のオプション：**裁断レイヤーのみ（レーザー）**、**ラベルを含める**、**線幅**、**透かし**（テキストと不透明度。PDF ではすべてのページに繰り返し入ります）。

MCP サーバーを通じて AI が作成し、まだ誰も確認していないオブジェクトが図面にある場合、ダイアログで警告されます。ステータスバーから選択し、確認後にプロパティの**確認済みにする**を押してください。

### 実寸での印刷

タイル分割された PDF の先頭は**組み立てページ**です。シートの配置図と **50 mm の校正用の正方形**があります。各シートにはトリムマークとラベル（A1、A2、B1…）が付きます。

1. **100 % /「実際のサイズ」**で印刷します。「用紙に合わせる」や「大きすぎるページを縮小」は使わないでください。
2. **50 mm の正方形を測ります。** 正確に 50 mm でなければ、プリンターの拡大縮小設定を直して印刷し直してください。
3. 破線に沿って切るか、シートを重ねて、コーナーマークとシートラベルを合わせ、テープで貼り合わせます。

## 11. キーボードショートカット

### ツールとアクション

| キー | ツール | キー | ツール |
| --- | --- | --- | --- |
| V | 選択 | M | 移動 |
| L | 直線 / ポリライン | O | 回転 |
| R | 長方形 / 正方形 | S | 拡大縮小 |
| C | 円 / 3 点円 / 楕円 | I | 鏡像 |
| P | ペン（曲線） | Q | 配列 |
| A | 円弧（3 点） | W | トリム / 延長 / 分割 |
| X | 中心線 | E | オフセット |

| D | 計測 | K | 縫い線 |
| Z | 拘束 | H | 縫い穴 |
| U | 打ち抜き穴 / 長穴 | J | 合い印 |
| Shift+H / Shift+V | 左右 / 上下反転 | Shift+J | パスの結合 |
| Shift+X | 分解 | Shift+U / Shift+D | 和 / 差 |

これらのキーは、ツールバーの**ショートカット…**で変更できます。文字キーで、Shift の有無にかかわらず、キーの物理位置で判定されるため、どのキーボード配列や入力方式でも動作します。設定はブラウザごとに保存され、**すべてリセット**で既定値に戻ります。

## 12. カードケースを作る

1. **長方形**（R）：一度クリックし、`95`、Tab、`65`、Enter と入力します。裁断レイヤーに 95 × 65 mm の部材ができます。
2. **フィレット**（F）：`5` と入力し、**Shift+クリック**で角をクリックすると、四隅すべてが丸くなります。
3. **縫い線**（K）：輪郭をクリックしてから、内側をクリックします。既定の余白では、縁から 3.5 mm の位置に縫い線ができます。
4. **縫い穴**（H）：ピッチ **3.85** を選び、**すべての角に穴**にチェックを入れ、縫い線の上にカーソルを置いてクリックします。
5. **ラベル**（N）：部材の内側をクリックし、`カードケース · 2 枚裁断` と入力して Enter。
6. 輪郭を変更してみましょう。長方形を選択し、プロパティの**幅**を `100` にします。縫い線と穴が追従します。
7. **保存**（⌘/Ctrl+S）してから、**書き出し…** → PDF → A4 → 100 % で印刷し、50 mm の正方形を測ります。

## 13. トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| 何も描けない /「現在のレイヤーはロックまたは非表示です」 | レイヤーのロックを解除するか表示にするか、レイヤーパネルで別のレイヤーを選んでください。 |
| 印刷が少し小さい、または大きい | PDF が拡大縮小されています。100 % / 実際のサイズで印刷し、50 mm の正方形を測り直してください。 |
| フィレットが「この角には大きすぎます」と表示される | 案内に表示された最大の半径を使うか、辺を長くしてください。 |
| 縫い合わせる二辺の穴数が合わない | 計測 → 穴数 を使い、ピッチか一方の辺の長さを調整してください。 |
| 拘束の「競合」 | 新しい拘束が既存の拘束と矛盾しています。プロパティ → 拘束 から一つ削除してください。 |
| レーザーソフトで曲線が途切れて表示される | **曲線を短い直線で近似**を有効にして SVG を書き出すか、DXF を使ってください。 |
| ツールのショートカットが反応しない | テキスト入力欄にフォーカスがあるかもしれません。先に作図エリアをクリックしてください。キーが割り当て変更されていないか **ショートカット…** で確認してください。 |
