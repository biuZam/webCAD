# LeatherDraft

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português](README.pt.md) · [日本語](README.ja.md) · **한국어**

**밀리미터 단위**로 가죽 제품 패턴을 그리고 **1:1 실척**으로 인쇄하거나 재단할 수 있는 브라우저 기반 2D CAD 도구입니다.

모든 작업이 브라우저에서 이루어집니다. 계정도, 서버도 필요 없으며, 파일이 기기 밖으로 나가는 일은 없습니다. 앱으로 설치해 오프라인에서도 사용할 수 있고, Windows, macOS, Linux용 데스크톱 앱도 있습니다.

![LeatherDraft: 카드 지갑 부품을 그리고, 모서리를 둥글게 하고, 연결된 스티치 선과 송곳 구멍을 추가한 뒤 크기를 조정하고 내보내는 모습](docs/media/demo.gif)

> **상태: 1.0 이전.** 그리기, 가죽 전용 기능, 내보내기는 구현되어 있고 테스트도 마쳤습니다. 출시 전에 남은 작업은 실제 프린터에서의 인쇄 정확도 물리 점검, Inkscape, Illustrator, LightBurn과의 호환성 확인, 그리고 몇 가지 작은 항목입니다([`docs/TASKS.md`](docs/TASKS.md) 참고).

## 기능

**도면 그리기**

- 선(각 선분이 CAD처럼 독립된 객체)과 폴리라인, 사각형과 정사각형(모서리 반지름 지원), 원(중심 + 반지름, 세 점, 타원), 베지어 펜, 세 점 호
- 중심선(대칭축으로 사용 가능)과 수직선
- 라벨: 텍스트(부품 이름, "2장 재단" 등)와 결 방향 화살표. 노트 레이어에 배치
- 이동, 회전, 배율, 대칭(각각 복사본으로도 가능), 제자리 뒤집기. 직선형과 원형 배열
- 오프셋, 필렛, 모따기. 평행선. 자르기, 연장, 분할. 경로 잇기. 도형의 합집합과 차집합
- 점과 베지어 핸들을 직접 편집. 점을 부드러운 점과 모서리 점으로 전환. 점 추가와 삭제. 선택한 도형을 드래그해 이동
- 객체 스냅: 끝점, 중간점, 중심, 사분점, 교차점, 수직, 접점, 가장 가까운 점, 격자. 극좌표 추적과 객체 추적
- 구속 조건: 평행, 수직, 접함, 일치, 거리, 반지름. 첫 번째 객체는 고정하고 두 번째 객체가 움직이도록 풀이
- 정확한 값: 그리는 동안 좌표, 길이, 각도, 반지름을 입력. 속성 패널에서 숫자 편집
- 레이어(재단, 스티치, 참조, 노트)별 표시, 잠금, 색상. mm, cm, 인치 단위 표시

**가죽 전용 기능**

- 외곽선에서 일정한 여백으로 만들어지는 **스티치 선**. 외곽선과 연결되어 있어 외곽선을 편집하면 스티치 선도 따라옵니다.
- **스티치 구멍**은 마름모 송곳의 간격(2.7, 3.38, 3.85, 4.0, 5.0 mm 또는 사용자 지정)에 맞춰 원형 또는 사선 슬릿으로 만듭니다. "모든 모서리에 구멍"을 켜면 각 변의 간격을 조정해 모든 모서리에 정확히 구멍이 위치하도록 합니다. 실제로 송곳을 따라 찍는 것과 같습니다.
- 구멍은 스티치 선을 따라가고, 스티치 선은 외곽선을 따라가며, 모두 한 번의 실행 취소 단계로 처리됩니다.
- **변별 구멍 개수**와, 함께 꿰맬 두 변의 구멍 개수가 같은지 확인(측정 → 구멍 개수)
- 리벳, 스냅 단추, 버클용 **펀치 구멍과 슬롯**. 자주 쓰는 펀치 지름 지원
- **노치**: 어느 변에나 단일 또는 이중 맞춤 표시를 넣을 수 있으며, 절개형 또는 V 노치

**출력**

- **SVG**를 1:1(1 단위 = 1 mm)로 내보내며, 그룹마다 레이어를 만듭니다. 레이저 소프트웨어를 위해 곡선을 짧은 직선으로 바꾸는 옵션도 있습니다.
- **PDF**는 가정용 프린터를 위해 A4, Letter, A3에 겹침과 함께 나누어 출력하며, 재단 표시와 시트 라벨이 붙습니다. **50 mm 보정 정사각형**이 있는 조립 페이지도 포함됩니다. 대형 프린터용으로는 패턴 크기에 맞춘 한 페이지로도 출력할 수 있습니다.
- **DXF**(mm)는 레이저 및 CNC 소프트웨어용이고, **PNG**는 이미지 공유용입니다.
- 내보내기에 **워터마크** 텍스트를 넣을 수 있습니다(PDF에서는 모든 페이지에 반복됩니다).
- **SVG 또는 DXF를 실척으로 가져오기**: 참조 레이어에 올려 기존 패턴을 따라 그릴 수 있습니다.
- `.json` 프로젝트 파일 저장과 열기. 작업 내용은 브라우저에 자동 저장되며, 새로고침 후에도 복원됩니다.

### 실척 인쇄

PDF는 **100 % / "실제 크기"**로 인쇄하세요. "페이지에 맞춤"은 절대 사용하지 마세요. 그런 다음 첫 페이지의 50 mm 정사각형을 재어 보세요. 50 mm가 아니면 프린터의 배율 설정을 확인하세요.

Photoshop처럼 비슷한 도구들은 팔레트 칸을 함께 씁니다. 모서리에 삼각형이 있는 칸을 **마우스 오른쪽 클릭**(길게 누르기, 또는 칸에 포커스가 있을 때 → 키)하면 다른 도구를 고를 수 있습니다. 묶음은 선 / 폴리라인, 사각형 / 정사각형, 원 / 세 점 원 / 타원, 펜 / 호, 수직선 / 평행선, 필렛 / 모따기, 오프셋 / 시접, 펀치 / 노치, 좌우 / 상하 뒤집기, 잇기 / 분해, 합치기 / 차집합입니다. 사이드 패널은 상단 화살표로 접을 수 있습니다.

모든 도구와 작업 키는 도구 모음의 **단축키…**에서 바꿀 수 있습니다(브라우저별로 저장).

그리는 동안: **숫자를 입력하기만 하면** 입력 막대에 들어갑니다. **Tab**으로 칸을 이동하고, **Enter**로 적용, **Esc**로 취소, **Backspace**로 마지막 점을 지우고, **Shift**를 누르면 각도가 15° 단위로 고정됩니다. **Space + 드래그** 또는 가운데 버튼 드래그로 화면을 이동하고, 휠로 확대/축소합니다. **⌘/Ctrl+Z / ⇧⌘Z**는 실행 취소와 다시 실행, **⌘/Ctrl+S**는 저장, **⌘/Ctrl+O**는 열기, **⌘/Ctrl+A**는 전체 선택입니다.

## 개발

**Node ≥ 20.19**와 **pnpm 10**이 필요합니다(`corepack enable`을 실행하면 `package.json`에 명시된 버전이 적용됩니다).

```bash
pnpm install
pnpm dev                     # http://localhost:5173
```

개발 중 유용한 URL:

- `?fixture=acceptance`: PRD의 검수용 도면(100 mm 정사각형, 50 mm 원, 3.85 mm 스티치 구멍)
- `?fixture=perf`: 성능 확인용 2,000개 요소

픽스처 세션은 자동 저장되지 않으므로 내 작업을 덮어쓸 수 없습니다.

| 명령어 | 설명 |
| --- | --- |
| `pnpm test` | 단위 및 컴포넌트 테스트(Vitest). 개별 실행은 `pnpm test <파일>` 또는 `pnpm test -t "<이름>"` |
| `pnpm check` | 타입 검사, lint, 테스트, 번역 보고서 |
| `pnpm verify` | CI가 실행하는 전체 검사: 위 항목에 포맷 검사, 프로덕션 빌드, 번들 크기 예산 추가 |
| `pnpm build` / `pnpm preview` | 프로덕션 빌드(서비스 워커 포함)와 로컬 미리 보기 |
| `pnpm i18n:check` | 영어 이외 로케일에서 누락된 키 |
| `pnpm bundle:check` | 초기 다운로드는 gzip 기준 600 KB 미만이어야 함 |
| `BENCH=1 pnpm test perf.bench` | 2,000개 요소 성능 측정 |

패키지 설치가 느리다면 레지스트리 미러를 사용해 보세요. 예: `pnpm install --registry=https://registry.npmmirror.com`.

### 데스크톱 앱 (Tauri)

`src-tauri/`는 같은 Vite 빌드를 네이티브 창으로 감쌉니다(Windows, macOS, Linux). Rust 툴체인과 플랫폼 빌드 도구가 필요합니다([Tauri 사전 요구 사항](https://v2.tauri.app/start/prerequisites/)).

```bash
pnpm desktop:dev             # Vite 개발 서버 위의 네이티브 창(핫 리로드)
pnpm desktop:build           # 이 OS용 설치 파일을 src-tauri/target/release/bundle/에 생성
pnpm tauri build --bundles app   # macOS: .dmg 없이 LeatherDraft.app만 생성
```

웹 앱과의 차이: 저장, 열기, 내보내기는 네이티브 파일 대화상자를 사용하며(앱을 종료할 때까지 저장은 같은 파일에 계속 씁니다), 서비스 워커가 없습니다. 앱은 새 버전을 설치해 업데이트합니다. 자동 저장은 브라우저와 같이 동작합니다. Tauri는 교차 컴파일을 지원하지 않으므로 Windows 설치 파일은 CI에서 만듭니다. **Desktop** 워크플로(`.github/workflows/desktop.yml`)를 실행하거나 `desktop-v*` 태그를 푸시하세요. 워크플로 아티팩트로 Windows용 `.exe`(NSIS)와 macOS용 유니버설 `.dmg`가 생성됩니다. `src-tauri/icons`의 앱 아이콘은 `pnpm tauri icon public/icon.svg -o src-tauri/icons`로 `public/icon.svg`에서 생성합니다.

### 기술 스택

React 19 + TypeScript + Vite · 기하와 렌더링에 [Paper.js](http://paperjs.org) · Zustand + Immer(문서 저장소, 패치 기반 실행 취소/다시 실행) · 오프셋은 [paperjs-offset](https://github.com/glenzli/paperjs-offset), 대체 수단으로 Clipper · PDF는 jsPDF + svg2pdf.js(필요할 때 로드) · i18next · vite-plugin-pwa · Vitest.

### 전체 구조

- **도면은 밀리미터 단위의 단순한 JSON**이며 저장소에 보관됩니다. 모든 변경은 명령으로 처리되므로 실행 취소 횟수에 제한이 없고, 저장 파일도 단순합니다.
- **Paper.js**는 화면을 그리고 기하 계산을 맡지만, 데이터는 소유하지 않습니다.
- **연결된 요소는 원본을 바꾸는 같은 명령 안에서 다시 생성**되므로, 스티치 선과 구멍이 오래된 상태로 남지 않습니다.
- **PDF는 앱이 내보내는 것과 같은 SVG에서 만들어지므로**, 화면, SVG, 인쇄 결과가 서로 어긋나지 않습니다.

### 품질 기준

- **정확도.** 오프셋은 요청한 거리에서 0.02 mm 이내, 필렛 호는 실제 원에서 0.001 mm 이내를 유지합니다. PDF 배율은 테스트에서 PDF의 그리기 명령을 페이지 밀리미터로 다시 읽어 검증합니다.
- **성능.** 2,000개 요소(17,600개 스티치 구멍)를 약 12 ms에 다시 그립니다.
- **접근성.** 라이트/다크 테마에서 WCAG 2.2 AA 색 대비를 CI에서 강제하며, axe-core 감사에서 위반 사항이 보고되지 않습니다.
