# LeatherDraft

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português](README.pt.md) · **日本語** · [한국어](README.ko.md)

**ミリメートル単位**で革の型紙を描き、**1:1 の実寸**で印刷または裁断するためのブラウザ向け 2D 製図ツールです。

すべてブラウザ内で動作します。アカウントもサーバーも不要で、ファイルが端末の外に出ることはありません。アプリとしてインストールしてオフラインでも使え、Windows、macOS、Linux 向けのデスクトップアプリもあります。

![LeatherDraft：カードケースを描き、角を丸め、連動する縫い線と菱目打ちの穴を追加し、サイズを変更して書き出すまでの様子](docs/media/demo.gif)

> **ステータス：1.0 前。** 作図、レザー、書き出しの機能は実装済みでテストも行っています。リリースまでに残っているのは、実際のプリンターでの印刷精度の物理的な確認、Inkscape、Illustrator、LightBurn との互換性確認、そのほかいくつかの小さな項目です（[`docs/TASKS.md`](docs/TASKS.md) を参照）。

## 機能

**作図**

- 直線（CAD と同じく、各線分が独立したオブジェクト）とポリライン、長方形と正方形（角丸つき）、円（中心 + 半径、3 点、楕円）、ベジェのペン、3 点円弧
- 中心線（鏡像の軸として使用可能）と垂線
- ラベル：テキスト（部品名、「2 枚裁断」など）と革目矢印。ノートレイヤーに配置
- 移動、回転、拡大縮小、鏡像（いずれもコピーに適用可能）、その場での反転。直線状と円状の配列
- オフセット、フィレット、面取り。平行線。トリム、延長、分割。パスの結合。図形の和と差
- 点とベジェのハンドルを直接編集。点を滑らかな点と角の点で切り替え。点の追加と削除。選択した図形をドラッグして移動
- オブジェクトスナップ：端点、中点、中心、象限点、交点、垂線、接点、最近点、グリッド。極トラッキングとオブジェクトトラッキング
- 拘束：平行、垂直、接線、一致、距離、半径。最初のオブジェクトを固定し、二番目が動くように解決
- 正確な値：描きながら座標、長さ、角度、半径を入力。プロパティパネルで数値を編集
- レイヤー（裁断、ステッチ、参考、ノート）に表示・ロック・色の設定。mm、cm、インチでの表示

**レザー向けの機能**

- 輪郭から一定の余白で作る**縫い線**。輪郭に連動し、輪郭を編集すると縫い線も追従
- **縫い穴**は菱目打ちのピッチ（2.7、3.38、3.85、4.0、5.0 mm、またはカスタム）に合わせ、丸穴または斜めスリットで作成。「すべての角に穴」を有効にすると、各辺の間隔を調整して、目打ちを通すときのようにどの角にも必ず穴が入ります。
- 穴は縫い線に、縫い線は輪郭に追従し、すべて一回の元に戻す操作で処理
- **辺ごとの穴の数**。縫い合わせる二辺の穴数が一致しているかの確認（計測 → 穴数）
- リベット、スナップボタン、バックルに使う**打ち抜き穴と長穴**。よく使うパンチ径に対応
- **合い印**：任意の辺に単一または二重の合い印を、切り込みまたは V 字で付加

**出力**

- **SVG**（1:1、1 単位 = 1 mm）。グループごとにレイヤーを作成。レーザー用に曲線を短い直線に変換するオプションあり
- **PDF**（家庭用プリンター向け）：A4、Letter、A3 に重ねて分割し、トリムマークとシートラベル付き。**50 mm の校正用の正方形**を含む組み立てページ付き。大判プリンター向けには型紙サイズに合わせた一枚の用紙も選べます。
- **DXF**（mm）はレーザーや CNC のソフト向け、**PNG** は画像の共有向け
- 書き出しに**透かし**テキストを追加可能（PDF ではすべてのページに繰り返し入ります）
- **SVG または DXF を実寸で読み込み**、参考レイヤーに配置して既存の型紙をトレース可能
- `.json` プロジェクトファイルの保存と読み込み。作業内容はブラウザに自動保存され、再読み込み時に復元されます。

### 実寸での印刷

PDF は必ず **100 % /「実際のサイズ」**で印刷してください（「用紙に合わせる」は使わない）。その後、最初のページの 50 mm の正方形を測ります。50 mm でなければ、プリンターの拡大縮小設定を確認してください。

Photoshop のように、似たツールはパレットのボタンを共有しています。右下に三角のあるボタンを**右クリック**（長押し、またはフォーカス中に → キー）すると、別のツールを選べます。グループは、直線 / ポリライン、長方形 / 正方形、円 / 3 点円 / 楕円、ペン / 円弧、垂線 / 平行線、フィレット / 面取り、オフセット / 縫い代、打ち抜き / 合い印、左右 / 上下反転、結合 / 分解、和 / 差です。サイドパネルは上部の矢印で折りたためます。

すべてのツールとアクションのキーは、ツールバーの**ショートカット…**で変更できます（ブラウザごとに保存）。

描画中は、**数字を打つだけで**入力バーに値が入ります。**Tab** で欄を移動、**Enter** で確定、**Esc** で取り消し、**Backspace** で最後の点を削除、**Shift** で角度を 15° 刻みに固定します。**Space + ドラッグ**または中ボタンのドラッグで表示を移動し、ホイールでズームします。**⌘/Ctrl+Z / ⇧⌘Z** で元に戻す / やり直し、**⌘/Ctrl+S** で保存、**⌘/Ctrl+O** で開く、**⌘/Ctrl+A** ですべて選択します。

## 開発

**Node ≥ 20.19** と **pnpm 10** が必要です（`corepack enable` で `package.json` のバージョンが使われます）。

```bash
pnpm install
pnpm dev                     # http://localhost:5173
```

開発時に便利な URL：

- `?fixture=acceptance`：PRD の受け入れ用図面（100 mm の正方形、50 mm の円、3.85 mm の縫い穴）
- `?fixture=perf`：パフォーマンス確認用の 2,000 要素

フィクスチャのセッションは自動保存されないため、自分の作業を上書きすることはありません。

| コマンド | 内容 |
| --- | --- |
| `pnpm test` | 単体テストとコンポーネントテスト（Vitest）。個別の実行は `pnpm test <ファイル>` または `pnpm test -t "<名前>"` |
| `pnpm check` | 型チェック、lint、テスト、翻訳レポート |
| `pnpm verify` | CI が実行するすべて：上記に加え、フォーマット、本番ビルド、バンドルサイズの予算チェック |
| `pnpm build` / `pnpm preview` | 本番ビルド（Service Worker 付き）とローカルでのプレビュー |
| `pnpm i18n:check` | 英語以外のロケールで不足しているキー |
| `pnpm bundle:check` | 初回ダウンロードは gzip 圧縮で 600 KB 未満に保つ必要がある |
| `BENCH=1 pnpm test perf.bench` | 2,000 要素でのパフォーマンス測定 |

お使いの環境でパッケージのインストールが遅い場合は、レジストリのミラーを試してください（例：`pnpm install --registry=https://registry.npmmirror.com`）。

### デスクトップアプリ（Tauri）

`src-tauri/` は同じ Vite ビルドをネイティブウィンドウで包みます（Windows、macOS、Linux）。Rust のツールチェーンとプラットフォームのビルドツールが必要です（[Tauri の前提条件](https://v2.tauri.app/start/prerequisites/)）。

```bash
pnpm desktop:dev             # Vite の開発サーバー上でネイティブウィンドウを起動（ホットリロード）
pnpm desktop:build           # このOS向けのインストーラーを src-tauri/target/release/bundle/ に出力
pnpm tauri build --bundles app   # macOS：.dmg なしで LeatherDraft.app のみ
```

Web 版との違い：保存、開く、書き出しはネイティブのファイルダイアログを使い（保存はアプリを終了するまで同じファイルに書き込み続けます）、Service Worker はありません。アプリは新しいバージョンをインストールして更新します。自動保存はブラウザ版と同様に動作します。Tauri はクロスコンパイルできないため、Windows 用インストーラーは CI で作成します。**Desktop** ワークフロー（`.github/workflows/desktop.yml`）を実行するか、`desktop-v*` タグを push してください。Windows 用の `.exe`（NSIS）と macOS 用のユニバーサル `.dmg` がワークフローの成果物として生成されます。`src-tauri/icons` のアプリアイコンは `public/icon.svg` から `pnpm tauri icon public/icon.svg -o src-tauri/icons` で生成されます。

### 技術スタック

React 19 + TypeScript + Vite · 幾何とレンダリングに [Paper.js](http://paperjs.org) · Zustand + Immer（ドキュメントストア、元に戻す / やり直しはパッチで管理） · オフセットは [paperjs-offset](https://github.com/glenzli/paperjs-offset)、フォールバックに Clipper · PDF は jsPDF + svg2pdf.js（必要時に読み込み） · i18next · vite-plugin-pwa · Vitest。

### 全体の仕組み

- **図面はミリメートル単位のプレーンな JSON** で、ストアに保持されます。すべての変更はコマンドとして扱われるため、無制限に元に戻せ、保存ファイルも単純です。
- **Paper.js** は画面の描画と幾何計算を担当しますが、データは所有しません。
- **連動する要素は、元を変更する同じコマンドの中で再生成**されるため、縫い線や縫い穴が古くなることはありません。
- **PDF は、アプリが書き出すのと同じ SVG から生成**されるため、画面、SVG、印刷の間でずれが生じません。

### 品質基準

- **精度。** オフセットは要求距離から 0.02 mm 以内、フィレットの円弧は真の円から 0.001 mm 以内に収まります。PDF の縮尺はテストで、PDF の描画命令をページ上のミリメートルとして読み戻して検証しています。
- **パフォーマンス。** 2,000 要素（17,600 個の縫い穴）を約 12 ms で再描画します。
- **アクセシビリティ。** ライト / ダークテーマの WCAG 2.2 AA のカラーコントラストを CI で強制し、axe-core の監査で違反は報告されません。
